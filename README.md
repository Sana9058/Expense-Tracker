# 💰 Expense Tracker

A sleek and interactive **Expense Tracker** built using **HTML, CSS, and JavaScript**, designed to help you **track your income, manage expenses, and visualize spending trends** with dynamic charts.

This project is my milestone project as part of my **Unified Mentor internship**, focusing on enhancing my frontend development skills.

---

## ✨ Features

* 💵 **Track Income & Expenses** – Add income and record expenses in multiple categories.
* 📊 **Visual Charts** – Pie chart by category and bar chart for monthly expenses.
* 🗑️ **Easy Deletion** – Remove any expense with a single click.
* 💻 **Responsive UI** – Works perfectly on desktop and mobile screens.
* 📂 **Local Storage** – All data is saved in your browser for instant recall.
* ☁️ **Firebase Hosting** – Live deployment of the project.

---

## 🛠️ Tech Stack

* **Frontend:** HTML, CSS, JavaScript
* **Charts:** Chart.js
* **Data Storage:** Browser LocalStorage
* **Hosting:** Firebase Hosting

## 🌐 Setup and Installation

1. **Clone the repository:**
    ```bash
    git clone https://github.com/YOUR_USERNAME/Expense-Tracker.git
    ```
2. **Navigate to the project directory:**
    ```bash
    cd Expense-Tracker
    ```
3. **Local Development:**
    * Simply open the `index.html` file in your browser.
    * All features will work offline using browser LocalStorage.

4. **Firebase Hosting (Optional):**
    * Install Firebase CLI: `npm install -g firebase-tools`
    * Login: `firebase login`
    * Initialize project: `firebase init`
    * Deploy: `firebase deploy`
